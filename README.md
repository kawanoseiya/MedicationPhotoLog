# 撮るだけお薬手帳（SnapMed Log）

薬の説明書（薬剤情報提供書）や薬袋・ラベルを撮るだけで、薬の履歴を保存・検索できる iOS アプリ（Flutter）。
[SnapBP（撮るだけ血圧記録）](https://github.com/kawanoseiya/SnapBP) の姉妹アプリ。

**服薬判断・飲み合わせ判定・服薬通知は搭載しない。**

- 英語名は仮称。公開前に同名アプリ・商標を確認する
- Bundle ID: `com.s.kawano.snapmed`／iOS 16 以上

## 機能

| 機能 | 実装 |
|---|---|
| 撮影・取り込み | iOS の書類スキャナ（VisionKit）で複数ページを続けて撮影（紙の輪郭で自動トリミング・傾き補正）。写真ライブラリから複数枚取り込み。確認画面でページの追加・削除 |
| 文字読み取り | Vision（日本語・英語）で端末内 OCR。薬名・処方日・医療機関・薬局の候補を空欄にだけ入れる（`lib/logic/med_parser.dart`） |
| 確認・編集 | 写真と読み取り結果を並べて修正・保存。手入力も可。**どの項目も空欄で保存できる** |
| 履歴 | 処方日（無ければ登録日）の新しい順・月ごとの見出し。詳細で元の写真を拡大表示 |
| 検索 | 薬名・医療機関・薬局・メモ・読み取った全文 |
| 家族管理 | 人ごとに記録を分け、ホーム上部から切り替え |
| バックアップ | 記録と写真を1つの zip に書き出し（共有シート）、zip から復元（置き換え） |

保存項目: 対象者、処方日、薬名一覧、医療機関、薬局、メモ、元の写真、OCR 全文。

アカウント登録不要。写真・記録・OCR はすべて端末内。UI は日本語・英語（設定で切替可）。

## 収益化（SnapBP と同じ形）

無料・記録無制限＋バナー広告（非パーソナライズ・ATT なし）＋広告非表示の購入（買い切り `snapmed_remove_ads`／月額 `snapmed_remove_ads_monthly`、RevenueCat entitlement `pro`）。
広告はホーム・履歴タブの下部だけ。撮影・確認・編集の画面には出さない。

開発の詳細は [DEVELOPMENT.md](DEVELOPMENT.md)。
